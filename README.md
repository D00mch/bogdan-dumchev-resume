# Богдан Думчев — сайт-резюме

Статический адаптивный сайт-резюме: опыт в Додо Пицца, Дринкит, Люблю, Yarmina и Богарт; образование, результаты, видео о производстве Yarmina.

## Публикация через GitHub Pages

В настройках репозитория откройте **Settings → Pages** и выберите **Build and deployment → Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)**. Сохраните изменения.

Публичный адрес после активации: https://d00mch.github.io/bogdan-dumchev-resume/

Сайт не использует сервер и не требует сборки. Главная страница — `index.html`.

## Файлы

- `index.html` — сайт
- `resume.pdf` — версия резюме для скачивания
- `favicon.svg` — иконка
